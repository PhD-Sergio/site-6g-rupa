---
title: '6G Recursive User Plane Architecture'
description: '6G-RUPA is a recursive, RINA-based user plane architecture for flexible, scalable and energy-efficient 6G mobile networks.'
deck: 'A user plane for 6G mobile networks, built from one kind of layer repeated at every scale.'
---

Mobile networks still carry user data with protocols that have remained largely untouched for almost 30 years. 6G-RUPA rethinks that part of the network using the Recursive InterNetwork Architecture (RINA), aiming for networks that are more flexible, scale better and use less energy.
